## 來源存取限制

- 威秀官方兩分館頁面，`curl` 與標準 Node HTTPS client 回傳 HTTP 403 Access Denied；因此本版沒有把官方直連標示為完成。
- 威秀場次實作來源是開眼電影網第三方時刻表。回覆不把來源日期或讀取時間冒稱官方更新時間。
- 誠品保持原有官方時刻表解析與來源聲明。
